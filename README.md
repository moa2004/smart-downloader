# Smart Downloader

A media download helper with a Chrome extension companion.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/moa2004/smart-downloader)

Current Vercel URL:

```text
https://smart-downloader-eight.vercel.app
```

## Local

```bash
npm install
npm start
```

Open `http://localhost:5177`.

## Chrome Extension

Load the `chrome-extension` folder in Chrome using Developer Mode, or package it from `dist/smart-downloader-extension.zip`.
